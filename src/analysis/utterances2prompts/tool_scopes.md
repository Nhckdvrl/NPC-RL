# 工具作用域分析 (Tool Scopes Analysis)

本文档根据 `triggered_utterances.json` 中每种工具触发的随机抽样话语，总结了各个工具的预期功能和使用场景。

---

## 工具列表及其作用域

### 1. `search_item`

*   **作用域**: 当用户想要根据特定属性（如类型、价格、攻击力、防御力等）搜索或筛选物品时使用。用户通常会描述他们想要的物品特征，而不是直接指明物品名称。
*   **示例话语分析**:
    *   用户可能会问“有没有适合新手并且便宜的剑？” (暗示类型: 剑, 价格: 低, 适合度: 新手)
    *   “我想找一把攻击力高的双手武器。” (暗示攻击力: 高, 类型: 双手武器)
    *   “你们这里最坚固的盾牌是什么？” (暗示属性: 防御力高/最坚固, 类型: 盾牌)

### 2. `check_price`

*   **作用域**: 当用户明确询问特定已命名物品的价格时使用。
*   **示例话语分析**:
    *   用户在讨论某个物品（如“长剑”）后，可能会问“那这把长剑多少钱？”
    *   “我想知道这个治疗药水的价格。”

### 3. `check_type`

*   **作用域**: 当用户明确询问特定已命名物品的类型（例如，是单手剑、双手斧、轻甲、重甲等）时使用。
*   **示例话语分析**:
    *   用户可能会问“这个‘守护者之盾’是重型盾牌还是轻型盾牌？”
    *   “‘精灵之弓’是长弓还是短弓？”

### 4. `check_attack`

*   **作用域**: 当用户明确询问特定已命名武器的攻击力或伤害值时使用。
*   **示例话语分析**:
    *   “这把‘屠龙宝刀’的攻击力是多少？”
    *   “‘长剑’和‘短剑’比起来，哪个攻击力更高？” (这里可能触发对长剑和短剑分别的 `check_attack`)

### 5. `equip`

*   **作用域**: 当用户明确表示想要装备一个当前讨论的或刚刚购买/获得的特定已命名物品时使用。
*   **示例话语分析**:
    *   在购买“铁甲”后，用户说“好的，我现在就穿上它。”
    *   “这把‘晨星锤’看起来不错，我能现在装备吗？”

### 6. `check_basic_info`

*   **作用域**: 当用户想要了解一个特定已命名物品或任务的综合信息、基本描述或详情时使用。这通常是一个比较概括性的询问。
*   **示例话语分析**:
    *   对于物品：“能给我介绍一下这把‘两手巨剑’吗？” 或 “我想了解更多关于‘治疗药水’的信息。”
    *   对于任务：“这个‘商业护送’任务具体是做什么的？” 或 “跟我说说‘狩猎沙漠之虎’这个任务吧。”

### 7. `sell_request_confirm`

*   **作用域**: 当用户在经过一番比较或了解后，明确表示决定购买某个特定已命名的物品时使用。这通常是购买流程的确认步骤。
*   **示例话语分析**:
    *   “听起来‘短剑’更适合我，我就买这个了。”
    *   “好吧，我决定了，就要那把‘长剑’。”

### 8. `check_duration`

*   **作用域**: 当用户明确询问一个特定已命名任务需要持续多长时间或预计耗时几天时使用。
*   **示例话语分析**:
    *   “这个‘商业护送’任务大概需要几天？”
    *   “‘收集草药’这个任务要多久才能完成？”

### 9. `select_request_confirm`

*   **作用域**: 当用户在了解了任务信息后，明确表示选择或接受某个特定已命名的任务时使用。这通常是接受任务流程的确认步骤。
*   **示例话语分析**:
    *   “听起来不错，我接受这个‘调查废弃建筑’的任务。”
    *   “就这个了，我选择‘猎杀巨型老鼠’。”

### 10. `select`

*   **作用域**: 与 `select_request_confirm` 类似，当用户明确表示选择或接受某个特定已命名的任务时使用。从示例看，`select` 可能更偏向于用户主动、直接地选择，而 `select_request_confirm` 可能是在NPC推荐或解释后的确认。但两者界限可能比较模糊，具体取决于对话上下文。
*   **示例话语分析**:
    *   “这个任务听起来正合我意，我接了！” (指向特定任务)
    *   “是的，就选这个任务。”

### 11. `start`

*   **作用域**: 当用户在接受了某个特定已命名的任务后，明确表示准备好或想要立即开始该任务时使用。
*   **示例话语分析**:
    *   “我已经准备好了，现在就开始‘狩猎沙漠之虎’任务吧。”
    *   “谢谢你的帮助，我想马上出发去做‘商业护送’任务。”

### 12. `search_quest`

*   **作用域**: 当用户想要根据特定条件（如等级、时长、奖励、类型等）搜索或筛选任务时使用。用户通常会描述他们想要的任务特征。
*   **示例话语分析**:
    *   “有没有适合C级冒险者，并且报酬比较高的任务？”
    *   “我想找一个大约需要10天才能完成的任务。”
    *   “有没有难度适中的战斗类任务？”

### 13. `check_reward`

*   **作用域**: 当用户明确询问一个特定已命名任务的奖励是什么或有多少时使用。
*   **示例话语分析**:
    *   “完成‘收集草药’这个任务能得到什么奖励？”
    *   “这个‘商业护送’任务的报酬是多少？”

### 14. `check_level`

*   **作用域**: 当用户明确询问一个特定已命名任务的等级或难度时使用。
*   **示例话语分析**:
    *   “‘收集草药’这个任务是什么等级的？”
    *   “这个‘商业护送’任务对冒险者等级有什么要求吗？”

---

**总结**: 这些工具覆盖了游戏中与物品和任务相关的常见交互，包括信息查询、搜索筛选、以及流程性操作（如购买、装备、接受任务、开始任务）。每个工具都有其特定的触发条件和参数需求，主要依赖于用户话语中是否明确提到了物品/任务的名称以及他们想要执行的具体动作或查询的信息点。
